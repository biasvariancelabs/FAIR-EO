# FAIR-EO

This repository contains usage examples for the AiTLAS toolbox, developed as part of the OSCARS-funded [FAIR-EO](https://oscars-project.eu/projects/fair-eo-fair-open-and-ai-ready-earth-observation-resources) project. It provides dataloaders and example notebooks for 282 publicly available datasets: dataloaders are located in the datasets folder, and jupyter notebooks in examples. For datasets that lacked predefined train/validation/test splits, BVLabs created its own splits, available in the splits folder.
